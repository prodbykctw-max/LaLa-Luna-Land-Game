# Lala Luna Land — QA audit (2026-09-08)

Scope: `index.html` @ 3,532 lines (baseline was 2,053 — the codebase grew ~72% since the last audit: mount/glide
mechanics, extra creatures/NPCs and new asset versions are now in the game). Test build `index_test.html`,
headless Chromium + SwiftShader via Playwright, commit `b01bef6` ("The interact prompt is a star, and arrows
say when to jump"). All numbers below come from this run's `qa/out/*.json`; baseline figures are quoted from
`qa/report.md` only for comparison.

## Fixes applied after this audit (same session, branch `qa-fixes-2026-09-08`)

No GitHub write access was attached to this session, so these are committed to a local branch and delivered
as a patch rather than pushed/PR'd directly — see the accompanying hand-off write-up for how to apply it.

- **Reach (Delta #2, Green Theo/fans)**: `nearest()` (index.html) gave any not-yet-taken ability pickup a
  fixed priority over NPCs regardless of actual distance. Added the same "closer wins" override already used
  for the note-vs-npc/castle case (the R1/R2 fix): if the top pick is an `ability` but an `npc` candidate is
  actually nearer, the NPC wins. `qa/reach.mjs` re-run twice: `npc/Theo=OK` on Green both times, no other
  island's rows changed.
- **Frame budget / Sanity lights (F3)**: every `jelly` creature carried its own real-time `PointLight` (Sanity
  spawns 9 of them) on top of the dome's existing emissive glow — 9 of Sanity's 16 lights. Removed the
  per-jelly light and raised the dome's `emissiveIntensity` from .45 to .6 to keep the glow read without a
  scene light. `qa/framebudget.mjs` re-run: Sanity lights 16 → 7 (hub/gr/green/town unchanged at 4-5); no
  other island's tri/call numbers moved. Jelly is Sanity-exclusive (`index.html` config `creature:{type:"jelly"...}`
  appears only in Sanity's `cfg`), so no other island is affected.
- **Assets dead weight (A2 / corrected Delta #7)**: moved `lala-v3-raw.glb` (18.58 MB) and `lala-v3.glb`
  (2.5 MB) — confirmed genuinely unreferenced, unlike `lala-v2-original.glb` which stays — into a new
  `blender/` folder (source, not shipped). `qa/assets.mjs` re-run: `unreferencedOnDisk` now empty of these
  two entries as expected; live per-island request lists unaffected (nothing was ever requesting them).
- **Mobile touch targets (M2)**: `.topbtn`'s mobile media query set `min-height:32px`, and the ≥640px-wide
  landscape phones (844×390) fell back to the desktop pill's ~26px natural height entirely. Bumped the
  portrait rule to 44px and added a `body.touch`-scoped `@media (max-height:480px)` rule for landscape so
  short desktop windows aren't affected. `qa/mobile.mjs` re-run twice (a `small=2` on one run was resource
  contention from running two suites in parallel, contrary to the runbook's "sequential only" guidance — a
  clean solo re-run came back `small=0` everywhere): overlaps stay 0, small-target list is now empty on all
  5 islands × both orientations.

**Not fixed this pass** (flagged, not attempted): the frame-budget triangle/draw-call growth (Delta #1 — a
content/architecture question, needs a same-commit before/after to separate "new content" from "regression"
before deciding what to cut), the residual hill/stone camera-in-geometry hits (Delta #5 — already down
>90% from baseline, diminishing returns), and the newly-found Ollie/horse-tracking race (Delta #12 — needs a
real fix to the rig-attach ordering, not a one-liner).
